# 🎓 6th Semester GPA Calculator

A simple and user-friendly web application designed to calculate the GPA for 6th Semester students.

## 🌐 Live Demo

🚀 **Try the application here:**

[![Live Demo](https://img.shields.io/badge/Live-Demo-success?style=for-the-badge)](https://six-sem-gpa.onrender.com)

## ✨ Features

- Calculate Semester GPA automatically
- Enter grades for different subjects
- Automatic grade point calculation
- Simple and user-friendly interface
- Fast and responsive web application

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Gunicorn
- Render
